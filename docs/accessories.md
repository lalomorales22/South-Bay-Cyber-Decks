# Accessories

Add-ons that make a deck *yours*. All are optional, all are priced in
the configurator.

## Compute-adjacent

- **ESP32 + LCD status module** — second tiny screen for battery,
  network, CPU, and messages. The classic cyberdeck tell.
- **Second ESP32 coprocessor** — dedicated radio, sensor, or automation
  board so the main computer stays free.
- **ESP32-S3 + e-ink** (on request) — low-power status / notes display.

## Radio / antennas

- High-gain Wi-Fi (external, swappable)
- LoRa module + antenna — mesh / messaging
- GPS module + antenna
- Dual-band antenna set
- SDR receiver (receive-only)

Note: transmitting gear is the customer's responsibility to operate
legally (licenses, bands, local rules). We build the hardware; you own
the airwaves compliance.

## Power / carry

- Extra / hot-swap battery pack
- Solar input (regulator + panel mount, on request)
- Carry handle, shoulder strap, custom pouch
- Custom engraving / nameplate

## Display / input extras

- Second small display (status / terminal)
- External keyboard port, trackball, pointing stick
- Mounting rails, VESA / tripod mount (luggable builds)

If you want something not listed — a specific radio, a sensor, a
weird antenna — put it in the build notes. If we can source and power
it safely, we'll quote it.
